# Car model attribution

`car-concept.glb` is adapted at runtime from the Khronos glTF Sample Assets
**Car Concept** model.

- Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CarConcept
- Model and textures: Eric Chadwick, Darmstadt Graphics Group GmbH, 2024
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- License text: https://creativecommons.org/licenses/by/4.0/

The game hides the original license plate and steering-wheel emblem and applies
its own teal paint palette at runtime. The underlying geometry and textures
remain credited to the original author.
